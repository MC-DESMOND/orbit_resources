# 🛰️ GitOrbit

A growing collection of code resources, snippets, and templates — built while making real projects, broken down and shared so you don't have to start from zero.

Each resource here started as something I needed for my own work, then got cleaned up, documented, and put into orbit for anyone else to grab.

Follow the build breakdowns on [TikTok](#) / [YouTube](#), and find every resource on my [portfolio site](#).

## 🚀 What's in here

Every resource lives in its own folder with its own README covering what it does, how to use it, and why it's built the way it is.


## 🔧 Using a resource

1. Find the resource you want in the table above (or browse the folders)
2. Open its README for setup instructions and usage notes
3. Copy what you need into your own project

Most resources are framework-agnostic snippets or small, self-contained templates — drop-in first, tweak second.

## 🎥 How this works

Each resource gets a short breakdown video showing:
- What problem it solves
- How it works under the hood
- How to drop it into your own project

Links to the resource's folder and README are always in the video description / bio.
